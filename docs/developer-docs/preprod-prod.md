# Preprod To Production Process

---


## Steps to move from Prepod To Prodcution?

### Login to Portal
Login to https://portal.ondc.org/. If not already signed up, signup and register for it.

### Portal Dashboard
If not registered as Network Participant (Seller or Buyer or TSP), regsiter for it. Enter organization details.
If already registered, check details listed there.

### Steps to be completed.
From list of registered id, click Manage to move inside to check steps to be completed.
1. Sign NBBL agreement if not signed
2. Susbcribe for Preprod and generate keys
3. Create application as per ONDC API contract for domain you want to go Live.
4. Test your application with https://workbench.ondc.tech/scenario
5. Generate logs and submit to ONDC for verification.
6. For submiting to ONDC create "issue" from "Issue Resolution Hub" for QA team to review.
7. Once QA team approves, tasks 2.a would be completed by QA team.
8. For Network observability task please check Network Observability section.
9. For Live QA submit request for Live walkthrough.
10. Once all steps are marked as completed, Subscribe for Production
